# 排课系统

小学排课用的离线网页工具。整个软件就是一个 HTML 文件，双击即可在浏览器中打开，无需联网，也不用安装。

> 示例数据已脱敏：老师姓名均为历史人物化名，与真实人员无关。

## 使用
1. 下载 `排课系统.html`，用 Chrome、Edge 或 Safari 打开。
2. **课表**：可按班级、按老师或看全校总表。点格子修改课程，拖动格子可移动或互换；同一位老师同一节课被排进两个班时，格子会标红；可撤销、重做，可自动排课。
3. **检查**：列出老师撞课、各班教学任务是否排满、老师课时统计。
4. **基础数据**：增删班级、科目、老师和教学任务，可换老师、合并科目，可设置每周天数和每天节次。
5. **数据与导出**：导出或导入备份（JSON）、保存多套方案、导出 Excel（每班一张、每位老师一张，另附总表）、导出 CSV。

改动保存在当前浏览器中。换浏览器、换电脑或清除浏览器数据前，请先导出备份。

## 开发
- 源码在 `src/`，按模块划分，接口约定见 `CONTRACT.md`。
- 构建：`python3 tools/build.py`，生成 `排课系统.html`。
- 测试：`node tools/test_store.js`、`node tools/test_io.js`。
- `tools/extract.py` 用于从学校原有 Excel 课表提取数据，需要安装 xlrd。
